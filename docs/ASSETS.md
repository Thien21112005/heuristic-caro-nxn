# Where the shipped assets come from

| Asset | Origin |
|---|---|
| `src/assets/x_image_funny.png`, `o_image_funny.png` | The two meme-face pieces, in this repository since the project began. Their original source is not recorded. |
| `src/assets/icon/icon-*.png`, `packaging/caro.ico` | Generated from those two pieces on a drawn notebook page, by a one-off script during the notebook redesign (October 2026). |
| `src/assets/fonts/Mali-*.ttf` | [Mali](https://github.com/cadsondemak/Mali) by Cadson Demak, from `google/fonts`, under the SIL Open Font License (`Mali-OFL.txt`). |
| Inter | Bundled through the `flatlaf-fonts-inter` Maven dependency. |
| `src/assets/*.wav` | In this repository since the project began. Their original source is not recorded. |
| `docs/screenshots/*.jpg` | Captured from the running app. |
